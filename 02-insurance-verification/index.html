Insurance Verification Workflow

A simulated insurance verification workflow demonstrating how I review patient insurance information, confirm eligibility, identify exceptions, and document verification findings within an EHR environment.

Project Overview

This project demonstrates a mock insurance verification process completed using TherapyNotes EHR. The workflow follows the process of accessing the patient's profile, reviewing billing information, processing insurance verification, reviewing the response, and documenting the outcome.

6
