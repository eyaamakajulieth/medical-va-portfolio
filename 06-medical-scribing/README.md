# Medical Scribing

## Project Overview

Simulated Medical Virtual Assistant project demonstrating medical scribing, clinical documentation, and EHR documentation workflows.

## Tool Used

TherapyNotes

## Project Type

Simulated Training Project — Mock Patient Data

## Medical Scribing Workflows

### 1. Clinical Documentation
- Documenting patient encounters
- Recording patient-reported symptoms and medical history
- Organizing clinical information

### 2. SOAP Note Documentation
- Subjective: Patient-reported symptoms and medical history
- Objective: Relevant clinical findings supplied by the provider
- Assessment: Provider-documented clinical assessment
- Plan: Provider-directed treatment and follow-up plan

### 3. EHR Documentation
- Entering clinical notes into TherapyNotes
- Organizing encounter documentation
- Reviewing documentation for completeness
- Preparing notes for provider review

### 4. Documentation Quality
- Maintaining accurate clinical records
- Following patient confidentiality requirements
- Identifying missing information for provider clarification
- Supporting timely completion of clinical notes

## Skills Demonstrated
