# Lab Order Management

## Project Overview

Simulated Medical Virtual Assistant training project demonstrating a complete laboratory order management workflow using OptiMantra.

The workflow covers patient chart navigation, review of provider lab requests, lab order creation, requisition generation, documentation, patient communication, and follow-up appointment coordination.

## Tool Used

OptiMantra

## Project Type

Simulated Training Project — Mock Patient Data

## Lab Order Workflow

### 1. Patient Identification

Located the patient in OptiMantra and confirmed the correct patient record using identifying information such as date of birth.

### 2. Chart Review

Reviewed the patient's chart and confirmed relevant demographic and clinical information before proceeding with the lab order.

### 3. Review of Provider's Lab Request

Reviewed the provider's requested laboratory tests and the clinical reason for the order.

### 4. Lab Order & Requisition

Created the laboratory order and generated the corresponding lab requisition for the laboratory.

### 5. Patient Communication

Prepared a patient reminder regarding completion of the laboratory work and provided the necessary instructions while maintaining patient privacy.

### 6. Follow-Up Coordination

Coordinated and confirmed the patient's follow-up appointment with the provider.
